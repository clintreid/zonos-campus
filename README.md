# Zonos Campus

The public working record of the Zonos headquarters exploration at Tech Ridge, St. George, Utah. Ideas under exploration, not decisions.

## Pages

- `index.html` — The story: who Zonos is, why a building, how the collaboration runs.
- `site.html` — The site: the mesa rim, stairs and trail, climate, Tech Ridge context, the live development map (embedded).
- `view.html` — The view: the stepped-edge idea, its geometry, precedents, and open questions.
- `work.html` — How we work: voice and AI, whiteboards, walking meetings, the open-floor debate.
- `culture.html` — Culture: country rooms, the sci-fi thread, values, the community edge.
- `design.html` — Character: the deco study set, concept massings, facade studies, the globe.
- `ideas.html` — The idea list: every collected idea with its why.
- `board.html` — The board: the full inspiration gallery.

Shared: `style.css`, `site.js`, `favicon.svg`.

## Images

- `images/` — web-sized versions used by the pages.
- `images/pins/` — the inspiration board (49 images from the Zonos Headquarters Pinterest board).
- `originals/` — full-resolution sources moved off the Desktop (gitignored; stays local).

Every image on the site carries a corner tag (page letter + number, e.g. V2, D14, B27) so changes are easy to reference: H home, S site, V view, W work, C culture, D design/character, I ideas, B board.

## Publishing to GitHub Pages

1. Create a repository under your account (for example `zonos-campus`).
2. Push this folder to it.
3. Settings, then Pages, then Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site publishes at `https://<username>.github.io/zonos-campus/`.

## Content rules

This site is public. It carries no financial terms, no deal terms, and no architect-selection state. Those live in the internal campus ledger. Concept images are labeled as illustrations, not designs, and the voice throughout is exploratory: ideas, never rules.
